# 开发与验证

映述是原生 macOS 应用。产品介绍见[项目介绍](项目介绍.md)，完整操作见[使用说明](使用说明.md)。此文档记录可复现入口与验证范围，不包含本机项目、录音或账号配置。

## 构建

```sh
bash scripts/build-app.sh
```

输出为 `dist/映述.app`。应用层使用系统框架，没有 Swift 第三方包。当前在 Apple Silicon、Swift 6.4 工具链上，以 Swift 5 语言模式和 macOS 14 部署目标构建。建议使用 Xcode 26 / Swift 6.2 或更新工具链，才能编译全部新版 Speech 与 FoundationModels 分支；较旧 SDK 和其他系统组合仍需验证。

独立本地 AI 不包含在 App 中。在 Apple Silicon Mac 上显式准备：

```sh
bash scripts/prepare-local-ai.sh
```

脚本安装独立 Python / MLX，下载固定版本的公开模型并校验哈希与许可。不会读取私人项目或代替用户配置云端密钥。模型与环境位于应用自己的 Application Support 目录。详细依赖、模型和数据边界见[本地 AI 说明](本地AI说明.md)。

## 针对性检查

| 入口 | 实际验证的内容 |
| --- | --- |
| `scripts/check-models.sh` | 片段与感想绑定、编辑、排序、锚点、撤销、取消和项目兼容。 |
| `scripts/check-ai-speech-workflow.sh` | 注入语音结果，验证暂停、同帧落字、原位续播、原稿还原、一次撤销及迟到任务隔离。 |
| `scripts/check-local-ai-voice.sh` | 真正启动受控测试进程，验证 JSONL 协议、收尾、取消、超时、静音、内存上限及云端文字整理的状态边界。默认不访问真实模型或 API。 |
| `scripts/check-deepseek-text.sh` | 注入凭据和拦截网络，验证请求结构、错误脱敏、响应上限、拒绝跳转及真实 URLSession 取消。不会使用真实密钥或计费请求。 |
| `scripts/check-text-cleanup.sh` | 格式规则、保护词、数字、否定、内容保留和有限同音修正。模拟输出不是模型质量基准。 |
| `scripts/check-caption-editing.sh` / `check-caption-cleanup-state.sh` | 编辑与草稿、建议采用、撤销、取消、收齐尾字，以及旧回调不能覆盖新内容。 |
| `scripts/check-layout.sh` | 使用生成素材离屏渲染真实 SwiftUI 视图，检查尺寸、命中和状态布局；不读取桌面或用户项目。 |
| `scripts/check-live-photo.sh` / `check-import-workflow.sh` | 系统验证的合成实况配对、原位补全、撤销、项目往返和真实动态视频导出。 |
| `scripts/check-auto-edit.sh` / `check-story-order.sh` | 本机 Vision、真实音频节拍、时长阅读约束、排序及手动设置优先。 |
| `scripts/check-media.sh` / `check-caption-images.sh` | 生成照片与视频的真实解码、方向、音轨、字幕合成、PNG 输出及失败保护。 |
| `scripts/check-online-music-stream.sh` / `check-streaming-preview-state.sh` | 可控慢速音频响应和实际播放器时钟、渐进播放、缓存、互斥及取消。默认不是公网测速。 |

部分测试需要 `ffmpeg` / `ffprobe`，应用运行本身不依赖它们。媒体、布局和普通状态检查只使用生成或公开样本；联网检查需显式使用脚本的 `--online` 等选项。

### 真实模型检查

先准备本地 AI 环境，再生成诊断音频：

```sh
bash scripts/make-speech-fixture.sh
YINGSHU_LOCAL_AI_REAL=1 bash scripts/check-local-ai-voice.sh
```

诊断句来自 `Tests/fixtures/mandarin-diagnostic.txt`，用 macOS 系统语音在本机生成；仓库不分发该系统语音录音。真实 worker 的公开音频集成检查入口是 `Tests/LocalAIWorkerChecks.py --integration`，需由准备好的 AI 环境中的 Python 运行，测试选项与来源见该文件。

## 已验证与仍需验证

0.11 的本机验证包括实际 Qwen ASR / 文字模型运行，以及 App 中固定公开短句的真实 DeepSeek 连接测试；配置密钥不随仓库发布。界面离屏检查覆盖 34 个场景、357 项断言。可取消处理、失败保留原稿和旧任务隔离均有针对性检查。

这些结果没有建立用户日常口述的准确率基准，也没有证明优于商业输入法。真人口音、旅行噪声、各机型的真实 iPhone / iCloud 素材、旧版 macOS 和其他 Mac 的完整流程仍需持续试用。布局图是生成示例的真实视图渲染，不代表麦克风识别成功。

## 发布副本

```sh
bash scripts/package-release.sh
```

生成 `dist/release/映述-Mac.zip` 和 `SHA256SUMS.txt`。脚本只处理临时副本：移除编译调试路径和文件扩展属性，重新进行 ad-hoc 签名并核验，再打包。不会修改已安装应用或其中的钥匙串配置。模型、个人项目、原始录音和运行缓存都不在发布包中。当前没有 Apple 公证或 Intel 发行包。

发布源码前可检查 Git 跟踪内容：

```sh
python3 scripts/check-publication.py
```

该检查只读 Git 跟踪文件，核对本机数据边界、凭据模式、SVG 和入口文档链接；不会读取钥匙串、账号配置、Application Support 或忽略目录。历史本机验证日志与测试产物保留在本地，未纳入仓库。
