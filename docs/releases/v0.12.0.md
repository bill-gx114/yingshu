# 映述 0.12.0

这一版围绕原有的导入、口述、文字编辑、保存与导出流程做完善。

- **保存更清楚。** ⌘S 续存原项目，⇧⌘S 另存；标题显示未保存修改，本机恢复副本显示真实写入状态，失败可重试。旧项目恢复也保持正确的保存状态。
- **素材更容易找回。** 文件搬动后可重新关联，保留感想和剪辑，支持撤销；文件搬回原处后，重新检查即可恢复照片和视频预览。
- **时间轴保持一致。** 重新打开后保留保存时的安排；修复同片段换路径仍播放旧文件、旧缩略图晚到覆盖新图的问题。
- **编辑更顺手。** 文字编辑直接取得输入焦点，撤销使用文字自己的历史；原生控件优先处理键盘输入，菜单忙碌状态与主界面一致。长路径和错误说明可完整阅读。
- **导出更可靠。** 提前检查素材、配乐和文字，错误说明具体原因及修复办法；完善实况照片原图、链接文件和配乐署名旁文件的保护，失败与取消保留原素材及已有成品。

## 下载与更新

下载 **YingShu-Mac.zip**，解压得到“映述.app”。更新时先正常退出已有版本，再替换应用。项目恢复副本、已下载音乐和已准备的本地模型保存在应用数据目录，不包含在 ZIP 中。**SHA256SUMS.txt** 可核对下载完整性。

发行包面向 **Apple Silicon / macOS 14+**，采用本地 ad-hoc 签名，**尚未经过 Apple 公证**，没有 Intel 发行包。本版继续以预发布渠道提供；其他 Mac 和系统组合仍需验证。

独立本地 AI 模型与 Python / MLX 环境需要另外准备，已有环境可继续使用。口述用于生成文字，MP4 不包含口述录音或素材原声。处理范围与准备步骤见[语音设置说明](https://github.com/bill-gx114/yingshu/blob/v0.12.0/docs/本地AI说明.md)。

## 验证范围

保存与恢复、素材重新关联与撤销、键盘输入、真实照片/视频解码、三画幅 MP4、三画幅共 18 张 PNG 的文字与方向、失败及取消保护均有本机回归检查。使用生成素材的真实界面离屏渲染检查布局；没有把示例文字或注入语音数据当作识别准确率证据。

本轮未重新测试真人口述准确率、旅行噪声、其他 Mac 机型、VoiceOver 或真实 iCloud 素材。详细结果见[开发与验证](https://github.com/bill-gx114/yingshu/blob/v0.12.0/docs/开发与验证.md)和[产品优化记录](https://github.com/bill-gx114/yingshu/blob/v0.12.0/docs/2026-10-20-产品优化.md)。
