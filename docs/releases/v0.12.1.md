# 映述 0.12.1 · 补齐首次使用的 AI 准备流程

下载者不必克隆仓库或手动安装 Python。`YingShu-Mac.zip` 解压后包含：

```text
映述.app
准备本地AI.command
首次使用说明.txt
安装支援/
```

## 第一次使用

1. 将“映述.app”拖入“应用程序”。素材编辑、手写感想、项目保存和 MP4 / PNG 导出可以直接体验。
2. 若要使用独立本地 AI，双击解压目录里的 **“准备本地AI.command”**，保留同目录的“安装支援”文件夹。
3. 保持联网，等待固定版本的独立运行环境及约 **1.89 GB** 的两个模型准备完成。还需运行环境、缓存与解压空间；准备器会检查至少 6 GB 可用空间。无需 API Key、管理员密码、系统 Python、Git 或开发工具。
4. 看到 **“本地 AI 准备完成”** 后，正常退出并重新打开映述，在口述“…”菜单的“语音与整理设置”中选择 **“AI识别与整理”**。已有项目会保留原模式，需要手动选择。
5. 授权麦克风，用内置示例按 `R` 说一句、再按 `R` 结束，确认识别文字留在刚才的画面。

独立 AI 准备成功后可离线识别与整理。系统识别取决于 Mac 的 Apple 中文资源；可选 DeepSeek 整理不是必需步骤，也不会由准备器启用。

## 准备过程的保障

- 使用官方固定版本的 uv 和独立 Python，自举过程不要求开发工具；依赖只安装预编译包。
- 模型核对固定版本、许可和逐文件哈希；实际离线启动同版本 worker，确认两个模型加载就绪后才切换准备结果。
- 显示阶段、文件下载和日志位置；中断后可重跑并复用已完成文件。已有可用环境在准备失败时保留。
- 应用内的未准备状态提供对应步骤，下载首页和包内说明使用同一流程。

[完整准备、失败重试与隐私说明](https://github.com/bill-gx114/yingshu/blob/v0.12.1/docs/本地AI说明.md)

本包面向 **Apple Silicon / macOS 14+**，沿用预发布渠道和 ad-hoc 签名，尚未经过 Apple 公证。独立 AI 真实验收仍限当前 Mac，不能保证不同机型、口音和噪声下的速度与准确率相同。更新只需正常退出旧版并替换 App；已准备的模型保存在本机应用数据目录，无需每次更新重下。
