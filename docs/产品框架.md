# 映述：从回忆到一部小片

## 功能闭环

导入照片/视频及配对实况 → 按拍摄时间或显式智能叙事排序 → 本机场景分析并推荐配乐关键词 → 联网搜索/下载或选择本地音乐 → 不同时长的初剪 → 静音观看 → 按 R 暂停画面并口述 → 本机AI识别与所选模型整理文字 → 文字附着当前片段并续播 → 检查字幕/贴纸/手记 → 导出MP4或带字PNG图片。

默认按拍摄时间整理新导入素材，并开启时长智能编排。智能叙事由用户显式选择，不在每次导出时打乱。素材篮每行始终有移除按钮；右键、Delete 和撤销覆盖误导入场景。只移除引用和关联感想，保留原文件。自动分析不会删素材。手动移动切换为手动顺序，手动调时长/起点则锁定，自动结果不会覆盖。

## 数据与模块

- `Models.swift`：稳定片段ID、片段内感想、手调锁定、自动编排开关、项目和导出快照。旧项目可打开，新增可选字段兼容原JSON；缺少新设置的旧项目保留手动顺序并关闭自动时长。
- `AppModel.swift`：播放时钟、暂停口述/收尾续播、项目编辑、撤销、自动恢复；异步编排先分析后原子应用，失败或取消保留旧时间轴。导出按素材/文字/音乐指纹检查结果是否过期。
- `SpeechInput.swift` / `SpeechCapture.swift` / `ModernSpeechCapture.swift`：可注入的语音接口，macOS26+已安装中文资源时优先SpeechTranscriber；旧本机识别保留。显式系统服务模式才允许Apple联网。新版按音频范围合并最终/临时段，音频转换离开实时线程，不写录音，收尾最长4秒。`SpeechRecognitionOptions.swift`提供词表快照与官方增强资源的查询/显式准备/取消。
- `SpeechTextCleaner.swift`：基础格式规则与所选AI的文字整理，默认使用已准备的本地AI，另保留可用的FoundationModels本地备选；用户显式启用DeepSeek后才调用其文字接口。生成文字经过长度、数字、词表、否定、内容保留及改写幅度的保守守卫。正常独立AI口述自动落字并保留原稿；再次整理已有文字时用草稿和输入快照隔离，采用并完成后才落盘。
- `DeepSeekTextService.swift`：固定官方文字接口、钥匙串凭据、设备本地开关、有界响应、超时与真正取消。只提交文字和提示词，媒体与录音不提交；连接测试只用固定公开短句。失败保留完整识别稿，项目不携带云端凭据或开关。
- `LocalAISpeechCapture.swift`：独立AI模式的有界内存录音、串行转换16kHz单声道PCM、RMS过滤、120秒/4MiB上限。停止后整句交给真实模型，保留原稿和整理结果，不编造词时间戳。当前暂停模式直接绑定同一画面，正常录制一次落字并续播，不经建议弹窗。
- `LocalAIVoiceService.swift`：受固定AppSupport清单控制的独立Python进程和有界JSONL协议、共享预热、超时、实际进程取消、旧代次隔离、空闲释放。项目和模型输出不能指定执行命令。`Resources/ai_voice_worker.py`离线运行MLX Qwen3-ASR及Qwen2.5文字模型、校验公开模型资源、拒绝危险改写；`scripts/prepare-local-ai.sh`仅显式准备独立环境、固定版本公开模型及依赖，保留许可与哈希。不会运行远程模型代码。
- `DictationAlignment.swift`：词级音频时间与实际画面节点映射。当前录制冻结画面，因此整句始终落到同一片段；底层保留跨片段映射能力。
- `AutoEditEngine.swift`：本机 Vision 人脸与图像特征推理、像素质量和近邻重复；视频有界抽帧和运动采样；PCM FFT谱通量/能量瞬态及周期置信度；内容时长、文字阅读约束与真实音乐节拍的联合安排。
- `StoryOrderEngine.swift`：拍摄时序与明确回退、稳定导入序；本机 Vision 特征驱动的有限窗口叙事重排，保持素材与文字ID，支持取消。排序后按片段ID重定位播放节点。
- `LivePhotoImporter.swift`：同批原片的真实内嵌标识匹配。照片+MOV合并为一个动态视频片段，静图保留作海报/元数据；不按同名配对，不读取私人照片图库。
- `PhotoLibraryImporter.swift`：系统PhotosPicker只读取用户选择的素材；PHLivePhoto Transferable提供完整资源，原始字节流写入应用数据目录再交给项目。逐项原子提交、失败隔离、取消回滚本批，不请求全图库权限。
- `MediaEngine.swift`：ImageIO/AVFoundation 实际解码判定、方向处理、图像转视频、SDR合成、文字和音乐混合、原子MP4导出。
- `MusicRecommendationEngine.swift`：最多12段均匀抽样的本机Vision场景分类，结合本地感想与平均停留时长，生成可检索的风格关键词；不上传画面或原文。
- `OnlineMusicLibrary.swift`：公开曲库有界查询、关键词缓存、许可筛选与下载前复核，HTTPS流式下载、实际音频解码检查、文件校验及音频/许可原子缓存。下载曲目元数据随项目保存，MP4另存署名文本。
- `CaptionImageExporter.swift`：按文字可见组合生成有序PNG，视频/实况取对应帧，复用字幕渲染，分批目录原子发布；不触发自动时长编排。索引保留顺序、时间与原文。
- `OnlineMusicStream.swift`：当前生产试听，AVAssetResourceLoader+URLSession渐进传输给AVPlayer，真实播放时钟推进后更新UI；20秒/2MiB上限、15秒首缓冲超时、带版本标识的部分续传和3项/6MiB/10分钟内存缓存，停止立即取消。`OnlineMusicPreview.swift`保留常量/错误及旧片段测试路径，生产不等待整块前缀或PCM文件。
- `CompanionStickerRenderer.swift`：原创默认旅行者的25姿态序列、文字气泡与一次无声侧转；预览按片段内时间取姿态，MP4按全片绝对时间动画，PNG取静态帧。角色与四种样式共同避让，保留编辑ID。
- `EditorView.swift`：SwiftUI三栏工作台、可见删除、暂停口述状态、可取消编排进度、手动锁定与恢复自动。

字幕时间 = 片段起点 + 片段内开始位置。调序保持所属片段；编排会保留文字ID/文本，并重算显示区间。照片可以增加阅读时间；有文字的视频保留取景位置，受原片长度限制。锁定片段保持用户设定并提示阅读风险。

预览文字可直接点击纠错。渲染层携带稳定captionID与clipID，避让/过滤/缓存之后仍对应真实感想。录制时点击先等待唯一的stop流程收齐尾字，再编辑最终合并卡；草稿不受迟到语音回调覆盖。完成只改text，保留时间、样式与片段；纠错后导出接受当前时间轴，长段新增文字可显式重新编排。

## 算法边界

AI分析使用实际 Apple Vision 推理，不依赖网络或私钥，不等同于理解用户的情感与完整故事。重要程度是辅助提案。音乐卡点使用音频实测onset，在稳定性不足时明确降级；不从文件名推断节奏，不用固定BPM假装检测结果。音频分析最多180秒，视频最多6个候选，防止长素材占用无上限。

片段快慢由停留时长和视频选段决定。视频保持正常播放速度；目前没有变速曲线、自动裁脸或复杂转场。自动功能可取消、关闭、撤销，人工调整有优先权。

配乐推荐是可解释的场景/风格匹配，不做歌曲情绪的精确模型评分，不自动替换当前配乐。联网曲库当前只接受CC0与CC BY作品；需要署名的曲目保留说明，商业付费曲库属于后续接入。平台热门音乐可通过带字图片导出后，在剪映或抖音选择。

## 后续路线

1. 收集真实旅行素材试用：完成时间、文字返工次数、自动编排采纳率与满意度。
2. 用户可设置“多留一会儿”的私人意义权重，以及音乐节奏强度偏好。
3. 语音指令“上一张再留两秒”、口述纠错、可选保留旁白/环境声。
4. 更多文字排版与人脸避让、经过授权的商业曲库、字幕文件导出。
5. 素材打包、照片轻运动、变速曲线和转场。

后续功能不作为当前已完成能力。
