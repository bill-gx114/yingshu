# 小人气泡

这是一款可选的无声动态贴纸，用小人和文字气泡表达口述内容，不生成朗读或嘴型，不保存口述原声。

## 使用

- 在口述按钮右侧选择“小人气泡 · 无声”，再按R留下新感想。
- 已有文字：在右侧点开感想，选择“小人气泡”。文字、所属片段和时间保留，样式修改支持撤销。
- 预览画面中的小人/气泡仍可点击修改文字；暂停与拖动时，角色姿态由画面时间确定。
- MP4中气泡轻轻弹出，小人做一次约1.2秒的侧转，再停在正面。PNG保留静态人物与气泡，不包含动画或声音。

角色采用奶油帽子、珊瑚外套、鼠尾草背带和深绿鞋的原创黏土风旅行者；实际人物约占画面高度10%，与气泡共同参与四种文字样式的避让。长文字会按画布缩小，建议一次表达一个小感受。

当前先提供一款默认角色；上传头像/任意3D模型不在本版范围内。不会自动把已有字幕切成小人样式。

## 数据与渲染

由`scripts/make-companion.swift`通过SceneKit离屏生成25张透明三维姿态，运行期使用固定PNG图层，避免引入运行期模型加载和渲染依赖。原始资产与生成脚本均为本项目原创，按CC0提供；见内置《小人素材说明》。

预览、图片导出和视频导出共享气泡排版、角色姿态和避让规则。动作按感想的原开始位置计时，多句文字重叠导致分组拆层时不会重新转身；原有captionID/clipID仍用于点击编辑。

`dist/小人气泡效果预览.mp4`与同名PNG使用本项目原创海岸示例插画，不含私人照片。
