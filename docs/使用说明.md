# 映述

把一次出游的照片和视频导入，边看边说，让感想留在对应画面上。

1. 点“从相册选择”直接导入相册中的照片、视频与实况；本地文件用“从文件导入”。也可先使用内置示例熟悉操作。错误导入的素材可以点素材行右侧垃圾桶、右键“从项目移除”，或选中后按 Delete。只从项目移除，原文件保留；⌘Z 可撤销，关联文字也会一起恢复。
2. 新项目默认按拍摄时间排列；左侧“素材顺序”可选智能叙事、文件名、导入顺序或手动。默认开启“智能编排”：本机分析画面内容，按选中音乐的实际节奏安排长短。格式详情见《素材格式支持》。
3. 点播放；看到想说的画面时按 R 开始口述。**画面和配乐立即暂停**，不会在你说话时跳到下一张。再按 R 结束，文字附到刚才停住的画面，影片从同一位置继续播放。首次使用按系统提示允许麦克风与语音识别。
4. 直接点击预览画面中的字幕、贴纸或手记可以改错字。录制中点击会先结束这一句并收齐尾字，再打开编辑；完成/取消后按进入前状态恢复播放。也可在右侧检查感想、换字幕/贴纸/手记样式，展开“显示时间”微调，或贴满整个片段。口述只生成文字，声音不加入成片。

“开始口述”右侧的样式菜单提供“小人气泡 · 无声”。选中后，新感想会由一位小比例黏土旅行者配文字气泡展示；角色做一次轻柔侧转，不发声、不对口型。已有感想也可在右侧点开，选择“小人气泡”样式，支持撤销。原来的感想不会自动换样式。预览和 MP4 保留动作，PNG 留下静态人物与气泡。

点击右侧顶部 **“我的小人”**，先选一个灵感造型，再按喜好修改肤色、发型、发色、脸型、衣色和眼镜；左侧即时预览，也可填写十二字内昵称。点“就用这个”，新口述会使用小人气泡。勾选“以后新作品也用这个小人”可记为个人默认。取消不改变作品，确认后随项目保存、恢复与撤销。人物在本机生成，不需要 AI；已有小人气泡统一使用本作品的造型，其他样式保持原样。详细规则见《小人气泡说明》。

也可以点标题右侧 **“从照片找灵感”**，选一张清楚的单人正面照，本机参考配色、粗脸型、眼形、眼距和微笑，做成可爱的黏土草稿；再按照片点选发型和眼镜即可。分析可停止，失败不会清空当前造型，确认前不改作品。照片不会上传，原图、路径和原始五官点不写入项目；无需另下模型或 API Key。光线与背景会影响结果，可继续手动微调。
5. 选择画幅和配乐，再导出 MP4。素材、文字或配乐有变化时，导出前会重新检查编排；你会先看到更新后的时间轴，再选择保存位置。重新打开已保存的项目时，保持保存时的时间轴。取消编排不会更改原时间轴。

## 语音与整理设置

独立模型准备完成后，可选择“AI识别与整理”，在本机完成口述转写和文字整理，无需 API Key。未准备模型时可使用系统本机识别；详细准备步骤与模式区别见[本地 AI 说明](本地AI说明.md)。

设置中保留的可选云端整理默认不启用；启用条件、费用、发送范围和关闭方式集中见[可选云端文字整理](本地AI说明.md#可选云端文字整理)。

## 素材顺序与动态照片

- **拍摄时间**：读取照片 EXIF、视频创建元数据；没有拍摄时间时退回文件创建时间，再不足则保留导入顺序，并说明回退情况。拷贝文件的创建时间可能不是实际拍摄时间。
- **智能叙事**：本机 Vision 分析画面与人脸、相似程度，结合时间分组，在同一段旅程里做有限重排，让相似画面错开、照片与动态片段穿插，并考虑开场与收尾。不声称理解照片背后的私人意义或实际地点。
- **文件名 / 导入顺序 / 手动顺序**：适合已编号的素材或自己的叙事。前移、后移片段会切换为手动；排序可取消和撤销，字幕/贴纸跟随原片段。导出不会自行重新排序。旧项目以手动顺序打开，保留原时间轴；没有智能编排设置的早期项目会保持关闭时长自动调整，可自行开启。
- **iPhone 实况照片（Live Photo）**：优先用独立的“从相册选择”，系统会提供完整实况资源，应用保存照片与动态视频后识别为一段。无需先手动导出两个文件，也不访问未选中的图库内容。相册导入的素材持久保存在本机应用数据目录。也支持“从文件导入”同时选择原照片（HEIC/JPEG）和配对 MOV；验证后显示“实况”徽标，预览和导出都保留动态。
- 文件选择器的相册侧栏有时只提供 JPEG/HEIC 静态预览，单独图片不包含完整动态视频，此时仍可静态使用。界面会合并显示一条可展开的导入提示，不再逐张弹错误。用“从相册选择”重新选择同一实况，可补全已有静图并保留感想。不会仅凭同名误合并文件，未确认匹配的文件仍独立导入。从文件导入时项目引用照片与 MOV，请保留两份原文件；从相册导入的资源已保存在本机应用数据目录。这里的动态照片指 Live Photo，GIF/APNG/动画 WebP 暂不作为完整动画播放。

## 智能编排

- 画面在本机分析：使用 Apple Vision 的人脸与图像特征，结合清晰度、曝光、构图和相似画面，决定多停留还是更简洁。视频最多抽取六处候选，并比较邻帧变化，选取正常速度播放的一段；有感想的视频保留原来的画面位置。
- 音乐通过实际音频的瞬态和周期分析找节拍；只有节奏稳定时才对齐实测换镜点。舒缓配乐、静音或节奏不明确时，会明确提示改用画面内容编排，不强行编造 BPM。长音乐最多分析前三分钟，后面的画面按内容安排。
- 照片通常停留约 1.5–7 秒；文字较多可自动延长。视频及实况动态受原片长度限制。手动调整截取起点或时长后，该片段会锁定；点“恢复自动”可以重新交给编排。时长编排保留所有素材与当前顺序，不会替你删除照片。
- 更快或更慢体现为选段和停留时间的变化，视频自身保持正常速度；本版不做变速曲线。AI 无法判断一张照片对你的私人意义，你可随时手调，或关闭“智能编排”按当前时间轴导出。
- 添加感想后不立即打断续播；可点“重新编排”预览新的阅读时长，导出前也会检查。手调锁定或原片太短时会提示复查阅读时间。

快捷键：R 开始/结束口述，空格播放/暂停，方向键前后 3 秒，Delete 移除选中素材，⌘I 导入，⌘S 保存项目，⌘O 打开项目，⌘T 写一句，⌘Z 撤销，⇧⌘Z 重做。编辑文字时普通按键属于文字输入；录制/收尾期间不允许跳转、播放或修改素材。

同一片段上，同样式的口述文字如果显示时间重叠，会自动接成一张感想卡，保留原文字和口述顺序。多种文字同时出现时会自动错开位置。长段文字会缩小排版，建议一次表达一个小感受。

直接编辑只修改文字，保留片段、样式和显示时间。空白草稿不会默默删掉感想；取消保留原文，完成支持⌘Z撤销。纠错后导出尊重当前放置；如果增加了很长一段内容，可再点“重新编排”调整阅读时间。

## 中文口述与文字整理

在 Apple Silicon Mac 上准备好独立模型后：设置选择“AI识别与整理”，R开始并固定画面，R结束后由语音大模型识别、文字模型整理，直接落字并继续播放，无需逐句采用建议。无需API Key，也不依赖系统Apple Intelligence资格。录制中不逐字出字，首次加载与结束处理显示实际状态，可取消本句；每次最多120秒，音频只在内存，不上传或写入录音文件。新项目及未指定模式的旧项目在资源就绪时默认使用此模式，明确选择会随项目保存。

感想卡可查看识别原文并还原，支持撤销。整理会保守保留事实、数字、专词、否定和不确定语气；不合适的改写会退回完整识别稿并说明原因，无法保证所有错字或意思都能自动修复。这里使用Qwen开源模型的本机组合，与豆包/微信输入法的内部方案不同。模型、准备、性能和兼容限制见《本地AI说明》。退出时给当前口述最多5秒完成，逾时取消未完成处理并保存已有文字，避免长时间无法退出。

口述提示条右侧“…” → “语音与整理设置”可查看当前识别状态。选择“系统本机”时，macOS26+且资源可用会使用新版中文SpeechTranscriber，旧系统或缺少资源时采用兼容本机识别；不支持本机中文时会说明原因，不自动发送音频到服务器。增强资源未安装时，可主动准备官方中文模型，查看真实进度并随时取消。准备时暂停影片；不会在每次打开应用时下载。

在词表写入本次旅行的地点、人名和术语，例如“福冈、阿苏、白川水源”，用逗号或换行分开。完成设置后保存到当前项目；最多100个短词、每个最多64字，识别开始前取得快照，不影响正在说的这一句。词表只提高这些词的识别机会，不是强制替换规则。确有需要时可显式选择“Apple系统服务”，它允许系统通过Apple联网处理音频，也可能使用本机；不承诺一定比本机更准。

系统本机口述结束时会继续接收最终修正，最长4秒；有最终结果立即返回。超时仍保留临时文字并提示检查末尾。系统识别稿只自动规范空白和中文标点间距，不猜错字、不删语气或重复词，初始文字保留在项目中。实际效果仍受麦克风、口音和环境影响。

右侧选中感想，点“整理文字”：基础整理只处理空白与已有标点，任何Mac都可使用。可用的本地AI可进一步提供去口头重复和轻微语序整理的建议；先显示整理前与建议，点“采用建议”进入草稿，再点“完成”同步画面。随时恢复整理前或取消，完成后可⌘Z撤销，片段、时间和样式保持原值。生成中改字或关闭窗口会取消旧建议；换项目后旧结果不会回来覆盖。

系统FoundationModels整理需要macOS26+、Apple Intelligence使用资格及已就绪的中文模型；独立本地AI准备好后优先使用独立模型，不受这一资格限制。两者均不可用时会显示原因，基础整理和系统识别仍可使用。映述不会替用户开启系统设置或静默转到云服务。文本校对无法恢复没有识别出的声音，也不能保证识别错误一定能修复；人名、地名、数字和否定表达尤其需要确认。

## 项目与隐私

项目的**本机恢复副本**自动保存在 `~/Library/Application Support/YingShu/Autosave.yingshu`。底栏分别显示等待写入、已保存或失败；失败时可点“重试”，也可把项目保存到其他位置。恢复副本是最近一次编辑的本机保障。

**⌘S 保存项目文件**：第一次选择位置，之后保存到同一个文件。**⇧⌘S 另存为**：另选位置保留独立项目。标题旁的小圆点表示项目文件还有未保存的修改；悬停标题或保存按钮可查看路径。重启后恢复副本记住原项目的位置，⌘S 可继续保存。项目文件保存 JSON 格式的素材引用、文字、口述词表和编排设置，不包含录音或素材本体。请保留原素材位置；自动恢复副本不会代替对项目文件的主动保存。

素材移动、改名或未下载时，工作区显示“素材需要重新关联”。点“选择新位置…”，或使用“文件 → 检查素材位置…”，逐项重新选择原文件。照片与视频类型必须一致；视频须覆盖原来的裁剪范围；实况需要同时选择原照片与配对 MOV，通过系统核验后一起恢复。所选配乐也会检查，并可重新关联。修复保留感想、片段 ID、顺序、显示时间和手动时长，可 ⌘Z 撤销。文件已搬回原处时点“重新检查”。

导出前会检查所需画面和配乐，缺失时先打开关联面板。PNG 只检查含文字的画面，不要求配乐可用。实况的静态海报丢失时仍可从现存动态视频导出。原文件已损坏时，导出会说明出错素材，已有成品与原素材保留。

媒体分析、预览、音乐分析与视频导出在本机完成，无需第三方API Key。口述默认本机处理；显式选择“Apple系统服务”允许Apple通过网络处理音频。录音不写入文件或项目。未开启可选云端整理时，文字整理使用独立本地模型或可用的系统本地模型。

如果麦克风或识别被拒绝，可在“系统设置 → 隐私与安全性 → 麦克风 / 语音识别”中允许映述，随后重启应用。无法识别时仍可用“写一句”。帮助菜单提供“检查语音识别”：选择一段有人声的音频，单独检查中文服务，不启用麦克风，不更改项目。系统提示“语音资源未安装”时，在“系统设置 → 键盘 → 听写”中启用中文并等待资源下载。收尾超时会保留已识别文字，明确提示检查末尾。

打开或新建项目之前，当前非空项目会自动另存到 `~/Library/Application Support/YingShu/Recovered Projects/`，可从“文件 → 查看自动保留的项目”找回。项目不会复制私人素材。

## 配乐与输出

内置“沿途的风”“慢一点的午后”为本项目自行编曲、用代码生成的轻音乐，按 CC0 1.0 提供，可随成片分享。它们是简洁的自制配乐，不是商业曲库。也可以导入自己有权使用的音频。

导入素材后，应用会在本机抽样分析最多12段画面，并结合已有感想生成配乐风格。首次推荐会自动联网检索；只发送音乐关键词，不上传照片、视频或感想原文。新素材的推荐会更新自动关键词；你自己输入的搜索会保留。推荐不会自动替换当前配乐。

展开“推荐与联网曲库”，点击风格建议，或输入“轻柔钢琴”“想要轻快的钢琴”等常见中文风格，也可以输入英文曲名、作者或关键词。常见中文风格会转为曲库关键词；未知词保留原文检索。结果显示作者、来源和许可，点击“下载并使用”后才下载到本机。下载可以取消，失败会保留原配乐。选中的音乐可单独试听；开始口述或影片播放时会停止独立试听。

每条联网搜索结果都有“试听片段”。点击后边接收边播放，最长20秒，不再等待整块前缀下载和转码；不会选中它作为配乐，也不会写入已下载曲库。连接、缓冲和播放时都可停止；播放状态在播放器时钟实际推进后显示。切换曲目、播放影片、开始口述、新建/打开项目时会停止并取消实际传输，曲库折叠后仍有独立停止入口。

试听每次传输上限2MiB，仅放入小型内存缓存（最多3条/6MiB/10分钟），不写试听文件或项目；重复听已经缓冲的内容可更快开始。部分缓存续传核对ETag或Last-Modified，不把已更新的曲目与旧数据拼接。退出应用后缓存消失。支持MP3且来源必须支持HTTP分段请求，不支持时可点击来源页试听。喜欢后再点“下载并使用”保存整首。

首次出声取决于远端首包和带宽；来源慢时会显示连接或缓冲状态，超过15秒未能开始/恢复则明确停止，可重试或换曲。应用不能保证海外曲库秒开。

联网曲库只接纳明确的CC0或CC BY音乐，不提供任意热门版权歌曲的下载。CC BY分享时需要署名；下载会保留许可记录，配乐区域可复制署名，MP4导出后旁边会附带`.music-credit.txt`。来源页可能还有采样创作者等完整说明，发布时请一并核对。详细规则见《配乐曲库说明》。下载后可离线使用，项目记录音乐文件路径，迁移时要一并携带。

点击顶部“导出短片”旁的下拉菜单，选择“导出带字图片…”，再选择保存文件夹。应用会新建一批按序号命名的PNG，只包含有文字的画面；同一素材里的分时文字会分图导出，重叠时按可见组合出图。字幕、贴纸、手记沿用预览样式与当前画幅。视频和实况照片会截取对应帧，图片不含声音。整批附有索引和说明，可直接按文件名顺序导入剪映或抖音，再选平台配乐。图片导出尊重当前时间轴，不触发音乐卡点重排。

导出 MP4 包含画面、文字、所选配乐，不含视频原声或口述录音。输出为 H.264 SDR，完整画面等比留黑，不做复杂转场。项目迁移到另一台电脑时需要携带原素材。本地构建版尚未经过 Apple 公证，用于当前 Apple Silicon Mac 本机运行。

## 画面文字的末尾标点

新识别与整理的画面文字默认省略末尾句号，保留问号、感叹号、省略号与句中句号。已有文字可点“基础整理”处理；原始识别文字仍原样保留，可随时还原。旧作品不会自动批改，手写文字直接保存时保留你输入的标点。
