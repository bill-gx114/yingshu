# 映述的本地 AI 口述

下载应用后，可以先导入素材、手写感想和导出作品。独立本地 AI 是另行准备的口述方式：用两组本机模型完成语音识别与文字整理，无需 API Key。应用包不包含大模型和运行环境，打开应用也不会静默下载它们。

## 不知道该下载哪个？

**[只下载 YingShu-Mac.zip（App＋AI 准备器）](https://github.com/bill-gx114/yingshu/releases/download/v0.14.0/YingShu-Mac.zip)。** ZIP 约 15 MB，里面已有“准备本地AI.command”；解压后双击它，才会下载约 1.89 GB 的模型。GitHub 的“Source code／源代码”不是 App 安装包，“SHA256SUMS.txt”只是可选校验表。

第一次使用请先看 **[从下载到用上 AI：6 步图文指南](下载与AI安装指南.md)**，再阅读本页的模型、设置和隐私细节。

## 先选择适合自己的开始方式

| 方式 | 现在可以做什么 | 准备要求 |
| --- | --- | --- |
| 先体验编辑与导出 | 打开内置示例或导入自己的素材，写字、改样式、保存项目、导出 MP4 / PNG。 | 直接打开应用，无需独立 AI 模型。 |
| 系统本机识别 | 使用 Mac 的中文语音资源把口述转成文字。 | 授权麦克风及语音识别；可用性取决于 macOS 和已安装的中文资源。缺少资源时按应用提示处理。 |
| AI 识别与整理 | 用独立模型在本机识别整句口述、整理文字并放回画面。 | 按下方流程显式准备运行环境和两个模型，完成后在设置中选择此模式。 |

应用要求 Apple Silicon（M 系列）Mac 和 macOS 14 或更高版本。目前独立模型仅在一台 macOS 27 / M5 Mac 上完成真实验收；其他机型和系统版本尚待验证。应用的最低系统要求不等于独立 AI 已在所有对应设备上通过验证，也不能据单机测试承诺其他设备的速度或识别表现。

## 从下载包双击准备

1. 从 GitHub Release 下载 `YingShu-Mac.zip` 并解压。保留“准备本地AI.command”和同文件夹里的配套文件；普通下载者不需要克隆仓库或输入安装命令。
2. 阅读“首次使用说明.txt”，再双击 **“准备本地AI.command”**。它会打开终端窗口，列明下载内容和来源。准备器本身无需管理员权限、API Key、Git、系统 Python 或开发工具，会自行准备固定版本的独立 uv / Python 及所需依赖。
3. 保持联网，按窗口提示等待各阶段完成。语音模型约 **1.01 GB**，文字模型约 **0.88 GB**，合计约 **1.89 GB**；运行环境和下载缓存还会占用额外空间。准备器会检查可用空间，若提示不足，请按窗口说明腾出空间后再运行。下载时间取决于网络，首次准备不承诺固定时长。
4. 只有看到 **“本地 AI 准备完成”**，才表示准备成功。准备器会核验模型文件，并离线启动随此版本发布的识别组件，确认两个模型实际加载就绪后才显示这句话。仅看到下载进度到 100%，还不代表全部准备完成。
5. 按 **⌘Q 退出映述，再重新打开**（无需重启 Mac）。进入示例或作品，点口述提示条右侧的“…” →“语音与整理设置…”，先选 **“AI 识别与整理”**，确认“本机 AI 运行环境”显示 **“本地 AI 已准备”**，再点右下角 **“完成”** 返回编辑器。已有项目会记住先前模式，准备器不会替项目切换；设置窗口打开时无法录制。
6. 没有素材时先点 **“先试一下”** 载入示例。点击“开始口述”或按 `R`，按系统提示授权麦克风，说一句短感想，再点击“录制中 · 点击结束”或按 `R` 结束。应用会在识别、整理后把文字放回刚才的片段，并从原位置续播；这一步用于确认这台 Mac 上的实际口述链路可用。首次加载模型可能需要等待，界面会显示真实阶段，可取消本句处理。

若 macOS 阻止首次打开应用或准备器，请先确认来自本项目下载页、核对校验文件，再按 [Apple 官方打开步骤](https://support.apple.com/zh-cn/102445)处理该项目；不要关闭全局安全检查。

准备一次成功后，不必每次打开应用都运行准备器。更新“映述.app”通常可以继续使用这台 Mac 上已准备的资源；移动应用到另一台 Mac 时，需在那台 Mac 上另行准备。

## 失败或中断时怎么继续

| 看到的情况 | 下一步 |
| --- | --- |
| 下载超时、连接失败，或中途关闭了准备窗口 | 恢复网络后，再双击同一个准备器。已有缓存可复用，无需先删除所有资源。 |
| 提示空间不足 | 为模型、运行环境和缓存腾出空间，再运行准备器；1.89 GB 只是模型大小。 |
| 准备器以失败结束 | 先看最后显示的失败阶段和日志路径。没有出现“本地 AI 准备完成”时，不能视为准备成功。 |
| 已显示完成，应用仍提示未准备或仍在使用系统识别 | 正常退出并重新打开应用，在“语音与整理设置”查看本地 AI 状态，并主动选择“AI 识别与整理”。仍异常时保留准备日志中的错误信息。 |
| 第一次口述结束后正在加载或处理 | 根据界面的真实阶段等待；也可以取消本句处理。首次加载需要时间，反复点击录制或重新下载模型不能代替等待加载。 |
| 识别结果不对或整理未被采用 | 检查麦克风输入、词表与原始识别文字。模型会犯错；准备成功不等于所有口音、噪声和人名都能准确识别。 |

准备日志保存在 `~/Library/Application Support/YingShu/AI Runtime/setup-logs/`，文件名为 `prepare-时间戳-进程号.log`。准备窗口会给出本次日志的位置；也可在 Finder 的“前往 → 前往文件夹…”中粘贴上述目录找到它。日志可能包含 Mac 用户名和本机路径，分享前请检查这些信息。修复期间仍可继续编辑、手写感想和导出；系统本机识别在资源可用时也可使用。

模型与独立运行环境保存在 `~/Library/Application Support/YingShu/AI Runtime/`。准备器不读取项目或私人素材，也不修改系统 Python 或其他项目环境；重复运行会复用已有缓存，并重新验证准备结果。

## 联网范围与本机处理

准备器会连接 GitHub（Astral uv / Python）、PyPI（依赖）、Hugging Face（公开模型）及这些来源使用的文件 CDN。下载由双击准备器主动发起，不使用用户的 Hugging Face 密钥。模型使用固定版本，核对许可与逐文件哈希，不加载模型仓库的远程 Python 代码。`manifest.json` 记录模型路径、准确版本、来源、许可、文件 SHA256 与依赖版本；模型实际加载就绪后才切换到新准备结果。

语音使用 Qwen3-ASR-0.6B 的 MLX 8bit 版本，文字使用 Qwen2.5-1.5B-Instruct 的 MLX 4bit 版本。未开启可选云端文字整理时，准备成功后的独立 AI 链路可离线运行，不使用 API Key，不上传口述音频、文字、照片或视频。原始和整理后的文字随项目保存在本机。

每次口述最长 120 秒，音频只在内存收集，不写录音文件，也不加入项目或成片。录制期间不逐字转写，结束后整句处理；正常落字无需逐句采用建议。取消会结束本句处理，保留已有感想。启动失败、资源损坏或识别失败会明确提示，不会自动切到联网语音识别。

词表可以提示地名和人名。模型可能听错或改错；应用会保守检查数字、保护词、否定、不确定表达与内容保留，未通过时保留完整识别原稿并说明原因。感想卡可查看和还原原文，支持撤销。对已有手改文字再次整理时，仍先显示建议，再由你采用和完成。

“系统本机”使用可用的 Apple 本机资源；若主动选择“Apple 系统服务”，Apple 可能通过网络处理音频。这两种模式与上面的独立模型准备分别设置。

## 可选云端文字整理

默认流程无需云端 API。DeepSeek 是额外选项，默认不启用；使用映述和准备上述本机模型，都不需要开通 DeepSeek 或填写它的 API Key。

“口述选项 → 语音与整理设置”中可保存DeepSeek API Key，测试连接，再开启“DeepSeek整理文字”。密钥只存本机钥匙串，不随项目、应用包或ZIP导出；输入框不会回填已保存的密钥，保存或关闭设置会清空未保存草稿。可随时替换或移除；移除会关闭DeepSeek。配置选择只保存在此Mac，不随项目传播。

在“AI识别与整理”模式下，语音仍由本机Qwen模型识别，随后只将本句识别文字和提示词发到DeepSeek官方接口。DeepSeek不是本应用的语音转写服务，不接收照片、视频或录音。使用 `deepseek-flash`、关闭思考模式，可能产生API费用；每句最多2000字符、请求最多20秒，无自动计费重试。系统识别模式下，DeepSeek可用于感想卡的手动整理；若显式选择Apple系统服务，音频可能按该模式由Apple处理，与DeepSeek上传范围分别说明。

DeepSeek可整理明确口吃重复、标点和高度确定的同音错字。输出仍检查数字、保护词、否定、不确定表达、内容遗漏和改写幅度；同音修正只允许少量可配对的中文同音字，不能证明语义必然正确。识别原稿始终保留。断网、超时、余额/权限问题或结果被拒绝时，完整保留原稿并明确提示；取消不会把迟到结果放进新口述。

“测试连接”只发送固定公开短句“今天今天风很轻”，不读取项目、感想、提示词或麦克风。测试成功只证明密钥和这条整理请求可用，不代表真人识别准确率已达标。手动整理已有文字时仍先生成建议，采用并完成后才改画面。

## 加载与性能边界

选择独立 AI 且资源就绪时，应用会尝试预热。首次加载仍需要时间；空闲约三分钟后退出推理进程释放内存，下次使用会重新加载。准备器成功说明运行环境和模型可以加载，不代表应用里的每次口述都已经处于热加载状态。

已有记录来自 macOS 27 / M5 / 16 GB 的少量测试样本：冷启动约 2.4–3.8 秒；一条 4.2 秒公开音频的热识别约 0.15–0.19 秒、整理约 0.17 秒。16 GB 是该次测试配置，并非据此确定的最低内存要求。MLX 测得峰值约 2.43 GB，不同测试进程 RSS 峰值约 1.55–2.23 GB，统计口径也不同。这些单机记录不能外推到其他设备、长句、口音或现场噪声场景。
