# 映述的本地 AI 口述

本机已准备独立的语音和文字模型。选择“口述选项 → 语音与整理设置 → AI识别与整理”后，按 R 开始并暂停画面，再按 R 结束；应用识别声音、整理表达、直接把文字放到刚才的画面，然后续播。正常口述无需逐句采用建议。新项目及未明确指定模式的旧项目，在资源就绪时默认使用此模式。

语音使用 Qwen3-ASR-0.6B 的 MLX 8bit版本，文字使用 Qwen2.5-1.5B-Instruct 的 MLX 4bit版本。这是开源模型的本机组合，不是豆包或微信输入法的私有接口，不能据模型名称承诺相同准确率。词表可以提示地名、人名；整理仅删除明确的口吃重复、少量填充音和规范表达，不补充未说过的事实。

模型可能听错，也可能提出不合适的改写。应用检查数字、保护词、否定、不确定表达与内容保留，检查不通过时使用完整识别原稿并显示整理未采用的原因。它是保守校验，不能证明语义必然正确。感想卡可“查看原文”和“还原识别文字”，单次还原可撤销；正常落字也能一次撤销。对已有手改文字再次点“整理文字”，仍先看建议再采用，避免覆盖手改。

每次口述最长120秒，原生端仅在内存收集16kHz单声道音频，最多4MiB；不写录音文件、不加入项目或成片。录制期间不显示逐字转写，结束后整句处理。取消会结束实际推理进程；准备和处理中可点“取消本句处理”，取消的本句不保存，原感想保留。启动失败、资源损坏或识别失败会明确提示，不把低质量后备识别假称为AI结果。

关闭DeepSeek时运行完全离线，不使用API Key，不上传口述音频、文字、照片或视频。仅第一次准备需要从PyPI和Hugging Face下载公开软件与模型；不使用用户的Hugging Face密钥。模型按固定revision、许可及逐文件哈希核验，不加载远程Python代码。原始和整理后的文字随项目保存在本机。

## 可选 DeepSeek 文字整理

“口述选项 → 语音与整理设置”中可保存DeepSeek API Key，测试连接，再开启“DeepSeek整理文字”。密钥只存本机钥匙串，不随项目、应用包或ZIP导出；输入框不会回填已保存的密钥，保存或关闭设置会清空未保存草稿。可随时替换或移除；移除会关闭DeepSeek。配置选择只保存在此Mac，不随项目传播。

在“AI识别与整理”模式下，语音仍由本机Qwen模型识别，随后只将本句识别文字和提示词发到DeepSeek官方接口。DeepSeek不是本应用的语音转写服务，不接收照片、视频或录音。使用 `deepseek-flash`、关闭思考模式，可能产生API费用；每句最多2000字符、请求最多20秒，无自动计费重试。系统识别模式下，DeepSeek可用于感想卡的手动整理；若显式选择Apple系统服务，音频可能按该模式由Apple处理，与DeepSeek上传范围分别说明。

DeepSeek可整理明确口吃重复、标点和高度确定的同音错字。输出仍检查数字、保护词、否定、不确定表达、内容遗漏和改写幅度；同音修正只允许少量可配对的中文同音字，不能证明语义必然正确。识别原稿始终保留。断网、超时、余额/权限问题或结果被拒绝时，完整保留原稿并明确提示；取消不会把迟到结果放进新口述。

“测试连接”只发送固定公开短句“今天今天风很轻”，不读取项目、感想、提示词或麦克风。测试成功只证明密钥和这条整理请求可用，不代表真人识别准确率已达标。手动整理已有文字时仍先生成建议，采用并完成后才改画面。

应用打开后会预热；首次加载仍需要时间，空闲约三分钟后退出推理进程释放内存，下次会重新加载。当前M5/16GB样本冷启动约2.4–3.8秒；一条4.2秒公开音频的热识别约0.15–0.19秒、整理约0.17秒。只有单机少量样本，不能外推所有音频、长句或噪声场景。MLX测得峰值约2.43GB，不同测试进程RSS峰值约1.55–2.23GB，两者统计口径不同。

## 在另一台 Apple Silicon Mac 上准备

应用包不包含两组大模型及Python运行环境。在本项目目录运行 `bash scripts/prepare-local-ai.sh`，完成后重新打开应用。准备脚本安装独立Python3.12、固定版本MLX依赖并验证公开模型，放在 `~/Library/Application Support/YingShu/AI Runtime/`。不会修改其他项目环境。当前语音资源约1.01GB、文字资源约0.88GB，另有运行环境；已有缓存可复用。当前仅在本机macOS27/M5验收，其他机型和旧系统仍需验证。

`manifest.json`记录模型路径、准确revision、Apache-2.0许可、来源、每个文件的SHA256及依赖版本。请保留该目录；移动应用不会自动携带模型。重新运行准备脚本可修复缺失资源，不会读取项目或私人素材。仍可显式选择系统本机模式。
