# 我的小人 · 0.14

## 产品判断

值得作为“小人气泡”的延伸：用户把自己的感想放进作品，也可以用同一个专属形象来讲述。形象在不同作品间延续，可能增加熟悉感与个人辨识度。这个假设尚未经过真实用户留存或分享数据验证，因此不把它称为已经证实的核心卖点。

本版的目标是：第一次打开的人选一个灵感或一张本机照片，点“就用这个”即可完成；想更像自己的人，再修改几个离散选项。不引入账号、照片云端上传、模型下载或复杂三维编辑。

## 页面与操作

- 主入口在编辑器右侧顶部“我的小人”。口述样式菜单和已有小人气泡卡片也可进入同一编辑器。
- 编辑器为 760 × 660 的原生窗口面板。左侧全身预览与可选昵称，右侧先给四个灵感造型，再给肤色、发型、发色、脸型、衣色和眼镜。
- 选项使用有限、可搭配的暖色系；沿用产品的奶油底、深绿文字与珊瑚色选中态。颜色有文字辅助标签和选中标记，键盘可访问。
- 六种发型、五种肤色、四种发色、三种脸型、六种衣色和三种眼镜。渔夫帽和光头不露出头发时，发色暂不可改，并说明原因。
- 四个灵感分别为经典旅人、山间小憩、海边的风、城市漫游；切换灵感保留已经填写的昵称。昵称可空，最多十二个字，不印在成片上。
- 取消不改作品。确认前完成整套姿态准备，显示可取消的准备状态；失败留在编辑器并允许重试。
- 确认后，新口述使用小人气泡；现有字幕、贴纸和手记保持原样。已有小人气泡统一使用本作品的形象。
- “以后新作品也用这个小人”决定是否记为个人默认。取消、打开旧作品、撤销与重做均不改写个人默认。
- 标题右侧提供“从照片找灵感”：原生选图，后台本机分析，生成草稿后继续微调；不另开繁杂向导。停止或取消让旧任务失效，失败保留原草稿。仅保存离散眼形、眼距、微笑与已有配色和脸型，原图及五官点不进入项目。“回到默认五官”仅清这些参考特征。
- 照片路线保留可爱的大头和玩偶比例，追求外观灵感，不能承诺识别身份或还原本人。发型与眼镜由用户选；光线或背景造成配色偏差时可手动修正。

## 保存与渲染

形象是作品的一部分，随项目保存、恢复和撤销重做。旧文件没有形象字段时使用经典旅行者，避免个人默认改变旧作品。新字段容错读取，不改变项目格式版本。

经典外观保留原有 25 张原创 PNG。个人造型在本机用程序化 SceneKit 几何生成同尺寸透明姿态，不需要外部模型或 AI。预览、PNG 和 MP4 共用人物与排版管线；视频只做一次轻柔侧转，没有朗读和嘴型。

只在内存缓存有限造型，不写入新的模型、人物缓存或用户照片。预览随选项刷新，完整姿态在确认和导出前可取消地准备。导出捕获项目当时的形象，后续操作不会替换正在导出的角色。

## 验收与发布

检查人物在全身预览和三种画幅中不裁切；确认每个外观维度真实改变角色。检查暂停时换形象立即刷新、播放头不动、原有文字点击区域仍可使用。保存与旧文件兼容、取消、默认、撤销重做、PNG 与真实 MP4 用独立测试作品验证。

发布沿用 Apple Silicon / macOS 14+ 预发布通道与 ad-hoc 签名。上一版安装包保留在 GitHub；如果出现项目读写或导出关键错误，可退出后换回上一版。没有公共线上性能或留存监测，不以本机通过代替所有设备验证。
