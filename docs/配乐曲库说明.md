# 配乐曲库说明

映述将本机画面分析与公开曲库分开处理。画面、原片、缩略图和感想留在本机；网络请求只包含查询关键词、公开曲目标识和音频下载地址。应用不需要用户填写API Key。

## 检索与推荐

导入成功后，从全片均匀抽取最多12段缩略图，使用Apple Vision分类并结合本地感想与平均停留时长，给出海边、自然、城市、相聚或夜色等风格建议。这是场景与风格的辅助匹配，不能判断某首歌对你的私人意义。画面不足时明确给出通用建议。推荐不会替换所选音乐。

曲库优先请求[ccMixter官方Query API](https://ccmixter.org/query-api)，其[第三方使用说明](https://ccmixter.org/about/attributionGenerator)开放检索和授权音乐使用；补充来源为[Openverse音频API](https://api.openverse.org/v1/)。每次只读取一页，结果有缓存和节流，不自动遍历全站。接口受服务状态和频率限制影响；无结果或网络失败时，应用显示原因，已有本地音乐仍可使用。

常用中文风格会映射为曲库关键词，未知曲名/作者按原文搜索。没有把随机热门歌曲或网页音频当作可下载配乐，也不绕过付费、登录或流媒体下载限制。

## 许可与下载

只接受[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)或纯[CC BY](https://creativecommons.org/licenses/by/4.0/)许可，排除NC、ND、SA及许可不明确的结果。CC0无需署名；CC BY要求保留作者、曲名、来源和许可链接，并标明音乐的截取、循环或音量等修改。保留曲目来源页，可核对作品提供者列出的完整采样署名及其它说明。

这些信息来自曲库的公开许可声明；记录声明与下载时间不代表映述取得作品所有权或另行提供商业授权。应用当前不接入商业付费曲库。Jamendo需要注册客户端并核对下载许可，本版不使用公开示例Key，也不直接下载其历史索引。

下载前重新查询官方元数据、核对曲目和许可。只接受HTTPS音频，限制60MB、15分钟；写入暂存目录后检查实际可解码音频，再将音频、许可JSON、署名TXT一起提交到：

`~/Library/Application Support/YingShu/OnlineMusic/`

项目保存已下载曲目的名称、作者、来源、许可、署名及本地文件位置，重启可继续离线使用。取消或失败不替换原配乐。导出MP4时，旁边生成同名`.music-credit.txt`供发布时粘贴；若文件无法写入，应用会明确提示从配乐区域复制。

导出带字PNG图片不使用应用配乐，适合之后在剪映或抖音里选择平台提供的音乐。

## 下载前试听

联网结果可渐进试听最长20秒，不先下载整首、不加入曲库、不更改项目配乐。每次HTTPS Range最多2MiB，核对206和Content-Range后，通过官方AVAssetResourceLoader接口渐进提供MP3数据给AVPlayer；不等整个响应完成、不先转成WAV、不写试听文件。音频数据会实际传输，试听不是“零下载”。停止、切歌、播放影片、口述或换项目时取消实际网络请求。

进程内最多3条/6MiB/10分钟的小缓存加快重听，退出即消失；只有播放器确认可播的数据才可缓存。部分数据续传携带If-Range并核对强ETag（或Last-Modified），资源变化会清缓存并提示重试，无版本标识时不拼接部分数据。完整缓存重听无需再次联网；部分缓存可先播已有内容并继续有界补充。

连接、缓冲和播放阶段都有可用的停止入口。界面以实际播放时钟推进确认开始播放，错误保持行内提示。超过15秒未开始或连续缓冲无法恢复时会停止；源站首包慢和带宽不足仍可能影响体验。

来源忽略范围请求或返回不合规内容时在响应头阶段停止，不退回整首下载；不支持的音频格式会提示打开来源。该路径不自动播放搜索结果，只有点击试听才开始。协议依据为[RFC 9110 Range](https://www.rfc-editor.org/rfc/rfc9110.html#section-14)，解码使用[Apple AVAudioFile](https://developer.apple.com/documentation/avfaudio/avaudiofile)。

当前播放使用[AVAssetResourceLoader](https://developer.apple.com/documentation/avfoundation/avassetresourceloader)与AVPlayer；AVAudioFile临时PCM转换只保留为旧测试兼容路径，不用于生产试听。
