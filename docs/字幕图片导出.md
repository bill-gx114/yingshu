# 把带感想的图片交给剪映或抖音配乐

在影述中导入素材并留下感想，选择需要的横屏、竖屏或方形画布，再点「导出图片」。选择保存位置后，App 会新建一个「字幕图片-…」文件夹，里面是按顺序编号的 PNG、`index.csv` 和文字说明。

把 PNG 按文件名顺序导入剪映或抖音，设置每张图片的停留时间，再选择平台里的音乐即可。字幕、贴纸和手记已经画在图片上，不必逐张重新添加；文字也已经成为画面的一部分，要修改时回到影述编辑后重新导出。

只有含非空感想的素材会生成图片。照片使用原照片画面；视频和实况照片截取这组文字对应时间段中间的画面，因此导出的 PNG 是静态图片，不包含动态播放、原声或音乐。

同一素材的感想分时出现，或几条感想相互重叠时，每个不同的可见文字组合都会有一张图片，避免漏字。这也意味着一张原照片可能导出多张带不同文字的图片。`index.csv` 保存对应的原素材文件名、片段内时间范围和完整文字，可参考开始/结束时间之差，在剪映中设置每张图片的时长。视频的「截图位置秒」指原视频中的时刻，已经包含裁剪起点。

三种画布分别为 1920×1080、1080×1920 和 1080×1080，输出为普通 8 位 sRGB PNG。素材按比例完整显示，空余部分铺黑色；字幕、贴纸和手记复用 App 预览的样式与避让规则。

整套图片先在临时批次中生成，完成后才一次保存。取消或读取失败不会留下可见的半套结果，也不会覆盖已经导出的文件或原始素材。索引只记录素材文件名，不写入原文件的完整磁盘路径。

开发验证可运行 `./scripts/check-caption-images.sh`：使用生成照片及有效的生成实况资源，验证三画幅、分时和重叠文字、离线 OCR、EXIF 方向、视频对应帧、取消和失败回滚。不会读取用户的私有素材。
