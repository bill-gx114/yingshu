# 映述 0.12：让作品能放心保存、找回和交付

日期：2026-10-20。版本：0.12。[下载与发行说明](https://github.com/bill-gx114/yingshu/releases/tag/v0.12.0)。

## 产品判断

“看到画面，停下来讲一句”已经是有辨识度的核心体验。当前更需要补齐创作工具的可靠性：作品能找回、画面与输出一致、失败能在原处修复、操作状态说真话。这轮保留原有暖白与珊瑚色的 Mac 工作区，没有增加新的创作概念或额外配置。

## 已完成

| 发现的问题 | 改成怎样 | 对使用者的意义 |
| --- | --- | --- |
| 底栏一直显示自动保存勾号，无法判断写入是否成功 | 恢复副本显示等待、成功、失败、未启用；失败可原位重试，悬停查看时间或原因 | 磁盘写入失败不会被成功图标掩盖 |
| 每次保存都重新选位置，重启后也忘记原路径 | ⌘S 续存原项目，⇧⌘S 另存；本机恢复副本记住命名文件位置，标题标记未保存修改 | 保存行为符合 Mac 使用习惯，撤销回保存状态会清除标记 |
| 照片、视频和音乐搬动后，只能把文件搬回原处 | 缺失横幅和重新关联面板；验证类型、可播放音轨、视频范围及真实实况配对 | 找回文件时保留感想、ID、顺序、选段和手调时长，支持撤销 |
| 打开已保存项目，首次导出可能再次自动改时间轴 | 载入时间轴作为已经确认的安排；只有后续创作变化才重新检查节奏 | 保存后重新导出的画面安排保持一致 |
| 同 ID 的视频换路径，预览仍可能使用旧文件 | 更新实际 AVPlayerItem；同路径恢复也重建失败播放器，旧缩略图回调核对项目与资源 | 预览使用当前关联的文件 |
| 素材丢失要等渲染后才报错，部分数据可能静默漏字 | 导出前检查素材和配乐；PNG 只检查带字画面；检查字幕关联、时间和 ID | 尽早给出可操作的修复入口，避免无效等待 |
| 导出路径经链接指回原素材时，只有路径比较不够 | 核对真实文件身份，提交前再次检查；拒绝把文件夹作为 MP4 覆盖 | 原文件和已有输出在失败时保留 |
| 连续重复口述可能合成超过导出上限的大卡片 | 超过合并上限时分别保留完整感想和原稿；旧长文字仍可打开修整 | 避免自动合并制造无法导出的文字，也不截断原文 |
| 菜单忙碌状态与主界面不一致，文字编辑撤销可能落到项目 | 统一禁用状态；文字编辑按自己的撤销栈；打开文字 sheet 后直接取得输入焦点 | 减少无效点击和意外的项目撤销 |
| 新项目可能沿用上个项目的自选配乐和选中状态 | 新项目重置项目配乐、画幅与选择；打开项目清除上个项目的导出提示 | 项目之间保持清楚边界 |
| 旧项目的缺省字段与恢复后的字段不完全相同 | 按实际含义比较默认设置，保留真实未保存修改 | 恢复旧项目不会误报未保存 |
| 原文件归位后列表正常，画面仍可能空白 | 重新检查时恢复失败的视频预览与缩略图；照片按文件变化补载 | 保持播放位置，不必再打开一次项目 |
| 长路径和素材关联错误只能读到前三行 | 在原有关联面板中完整滚读，并保留对应的修复操作 | 直接看完原因后继续处理 |
| 配乐署名旁文件可能指向原素材或已有文件夹 | 写入和清理前保护素材、项目、恢复副本及其链接和文件夹 | 成片保存成功时明确说明署名冲突，不删除原件 |

原来的用户素材和本地导出目录不参与测试。项目文件保持 version 1 的兼容格式；命名文件路径只写入本机恢复副本，不加入另存的项目文件。

## 验证

- 项目可靠性检查 20 组通过：命名保存、干净/未保存恢复、写入失败与重试、时间轴保真、旧默认字段语义、错误项目无污染拒绝、长文字完整恢复、各类素材重联及撤销、同路径失败播放器恢复、重复源的图片导出预检、原生控件按键透传和配乐署名旁文件保护。
- 新增导出安全检查：含符号链接、硬链接、导出途中目标变化、缺失配乐、无效字幕、文件夹保护和批次原子性。
- 既有模型、口述工作流、文字编辑、实况导入到动态 MP4、音乐下载任务隔离检查继续通过。
- 真实媒体检查覆盖三画幅、音乐循环、素材原声静音、手机编码、HDR 转 SDR、取消与失败保护；图片检查生成三画幅共 18 张 PNG，并检查文字、方向、时序与重叠。
- 离屏界面：44 场景、411 条通过断言、0 错误。查看了最小 1120 × 760 窗口中的中文长标题、未保存标记、缺失提示、口述控件，以及关联错误、保存失败的界面图片。

界面报告有隐藏窗口 AX 与视频合成帧等 58 条边界说明。此轮没有验证 VoiceOver、真人键盘操作、真实麦克风准确率、旅行噪声下的转写质量或其他 Mac 机型；没有重新调用模型或云端计费接口。离屏图不代表麦克风识别成功。

## 后续完善范围

继续完善现有能力，不扩展业务功能：

1. **减少重复操作。** 继续核验保存、恢复、素材重新关联、文字纠错和撤销的状态衔接，缩短从错误到继续编辑的路径。
2. **预览与输出一致。** 用现有四种文字样式和三种画幅检查中文长文、重叠、时间边界及真实手机媒体，保持画面、文字和配乐一致。
3. **响应与效率。** 衡量大批素材的导入时间、首帧等待、界面响应和内存峰值，减少重复解码、无效渲染与不必要的等待。
4. **真实使用与发行。** 以经过授权的真实素材验证识别纠错量和完整导出成功率，继续检查不同机型、macOS、iCloud 资源与应用升级过程。

本轮不新增业务功能。尚未完成的实测不以模拟结果代替，改进以现有流程的顺畅、稳定和可恢复为准。
