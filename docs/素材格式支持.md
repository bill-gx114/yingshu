# iPhone 素材支持与实际验证边界

验证日期：2026-10-18。样本均由本机生成，检查的是实际图片类型、视频编码和像素/时间信息，不以文件扩展名充当解码成功。`./scripts/check-media.sh` 检查通用格式，`./scripts/check-live-photo.sh` 检查实况配对和时间，`./scripts/check-photo-library-import.sh` 检查选中资源的持久化、取消和半失败处理。最后一项使用生成的 PHLivePhoto，不读取或改变用户实际图库。

| JPEG、PNG | ImageIO 解码、预览、拼接并导出 MP4；JPEG EXIF 方向已用四象限颜色验证 | PNG 未验证所有第三方 EXIF 扩展；透明部分铺黑色画布 |

| 竖屏、方向旋转 | 真实 90°显示矩阵，源与输出抽点比较；三种画幅均保持比例，空余铺黑 | 不自动转换空间/立体内容为可交互媒体 |
| 120 / 240 fps | 真正高帧率文件可导入并按文件时间轴输出，成片固定 30 fps | 不自动推断或恢复 iPhone「照片」的慢动作区间、速度曲线。要保留这些效果，请先在「照片」中导出编辑后的视频 |

预览与导出现在共用 ImageIO 主图选择和 EXIF 方向处理。视频按源媒体时间轴播放，拼接时不会插入原视频声音或口述录音；音乐来自单独配乐轨。

导入某一种扩展名失败，不代表同扩展名所有文件都不支持；导入成功也不表示其所有 Apple 专有编辑信息已被应用。这里列出的自动化样本没有替代真实设备素材验收。

## 从相册导入：推荐方式

点击 App 中独立的「从相册选择」，在系统界面中选中照片、视频或实况照片。选择一张 Live Photo 就会请求完整的照片和动态资源，不需要手动寻找或导出两份文件。普通文件选择器侧栏中的「照片」有时只交付静态 JPEG/HEIC，不能靠这张静图恢复没有交付的 MOV；需要动态时使用独立的相册入口。

导入器只处理 PhotosPicker 交付的已选项目，不遍历图库、不请求全图库授权、不通过资产 ID 回查未选项目。完整实况传输或写入失败时，该项进入汇总，不会丢掉动态后假装成功导入一张静图。

完成的资源保存到应用自有的 `Application Support/YingShu/Imported Media/批次UUID/项目UUID/`，项目不会引用 Picker 的临时 URL。保留系统提供的原文件名、原始字节和文件内拍摄日期。普通文件同时保留提供者交付的文件创建/修改日期；Live Photo 资源 API 不提供原始磁盘创建日期，不能据此声称恢复了该磁盘时间。

同批部分失败时保留完整成功项，并汇总失败；取消时删除本批尚未交给项目的副本，之前的导入保持不变。云端下载、磁盘写入和取消均不会报告假成功。

## 已经导出到 Finder 的实况资源

已有 Live Photo 原照片和 MOV 时，也可在一次文件导入中同时选中。名字可以不同；配对使用内嵌标识并经过系统验证，不按同名猜测。只有一张 HEIC 时仍然是静态照片。缺失、歧义或损坏时不会猜选或丢弃原文件。

导入不会重建「照片」中的循环/来回播放、长曝光等编辑模式。这里保存的是系统为已选实况对象交付的完整图像和视频资源。

## 拍摄时间与文件时间

照片优先读取 EXIF `DateTimeOriginal`，应用它自己的时区偏移和秒的小数；原始拍摄时间有效时，不会用较晚的扫描/编辑时间覆盖它。原始时间没有时区时按当前 Mac 的时区解释，跨时区素材在这种情况下可能有歧义。原始拍摄字段缺失或无效时才尝试数字化时间和 TIFF 时间。

视频读取 QuickTime 拍摄/创建日期，包括时区。文件创建时间另行保存，不冒充拍摄元数据；复制、下载素材可能改变文件时间。实况片段的拍摄信息优先采用对应照片的时间。没有拍摄时间的素材排序会使用文件创建时间作为回退依据。

## Apple 官方依据

- [Apple ProRAW 与 DNG](https://support.apple.com/en-ie/119916)：ProRAW 使用 DNG；Apple 也说明第三方 App 的呈现可能不同。
- [Mac 照片导出](https://support.apple.com/en-ie/guide/photos/pht6e157c5f/mac)：导出未修改原片时，Live Photo 会成为照片和视频两个文件。
- [PHAssetResourceType.pairedVideo](https://developer.apple.com/documentation/photos/phassetresourcetype/pairedvideo)：Photos 将 Live Photo 的动态视频作为独立成对资源；本版只验证用户选中的文件，不请求或遍历私人图库。
- [ImageIO 主图与解码](https://developer.apple.com/documentation/imageio/cgimagesource)：HEIF 主图可以不是索引 0。
- [DNG Image Properties](https://developer.apple.com/documentation/imageio/dng-image-properties) 与 [CIRAWFilter](https://developer.apple.com/documentation/coreimage/cirawfilter)：RAW 支持依赖相机与系统解码器，文件名本身不构成兼容证明。
- [Apple HDR / Dolby Vision 处理说明](https://developer.apple.com/av-foundation/Incorporating-HDR-video-with-Dolby-Vision-into-your-apps.pdf)：HDR 转 SDR 应明确设定 SDR 色彩空间和 8 位输出；本版使用 BT.709 视频合成。
- [iCloud notDownloaded 状态](https://developer.apple.com/documentation/foundation/urlubiquitousitemdownloadingstatus/notdownloaded)：代表本机尚无已下载原片。

- [PHLivePhoto 外部资源验证](https://developer.apple.com/documentation/photos/phlivephoto/request(withresourcefileurls:placeholderimage:targetsize:contentmode:resulthandler:))：用照片与视频资源文件生成系统 Live Photo 对象，验证失败时不合并。
- [QuickTime 内容标识](https://developer.apple.com/documentation/avfoundation/avmetadataidentifier/quicktimemetadatacontentidentifier) 和 [EXIF 原始拍摄日期](https://developer.apple.com/documentation/imageio/kcgimagepropertyexifdatetimeoriginal)：分别作为配对与拍摄时间的元数据依据。
- [PhotosPickerItem.loadTransferable](https://developer.apple.com/documentation/photosui/photospickeritem/loadtransferable(type:)) 与 [PHLivePhoto](https://developer.apple.com/documentation/photos/phlivephoto)：从系统已选项目加载完整实况对象。
- [从 PHLivePhoto 取得组成资源](https://developer.apple.com/documentation/photos/phassetresource/assetresources(for:)-2fedw) 与 [资源请求选项](https://developer.apple.com/documentation/photos/phassetresourcerequestoptions)：允许下载选中资源；本版使用带取消 ID 的 requestData 流写原始字节。
- [FileRepresentation 临时文件生命周期](https://developer.apple.com/documentation/coretransferable/filerepresentation/init(contenttype:shouldattempttoopeninplace:exporting:importing:))：系统文件只保证在导入闭包期间存在，因此本版先复制再交付持久项目路径。
