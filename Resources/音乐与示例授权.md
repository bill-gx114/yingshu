# 自制素材授权

“沿途的风”（breeze.wav）、“慢一点的午后”（afternoon.wav）为本项目用 `scripts/make-resources.py` 原创编曲并以纯合成器波形生成，无采样、无第三方录音。

三张示例插画与图标由 `scripts/make-art.swift` 原创绘制，不是真实旅行照片。

在法律允许的范围内，本项目对以上音频和示例插画适用 CC0 1.0 Universal 公共领域贡献，可复制、改编并随视频发布，无需署名。完整法律文本见 https://creativecommons.org/publicdomain/zero/1.0/legalcode 。本声明不覆盖用户另行导入的音乐、图片或视频。

联网下载的配乐逐曲适用来源声明的CC0或CC BY许可，不适用上述自制素材声明。应用为每首已下载音乐保留来源、许可JSON和署名TXT；MP4导出时旁边附带署名文本。完整规则见帮助菜单“配乐曲库与署名说明”。
