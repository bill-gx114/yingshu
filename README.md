## 看见那一刻，说出你的故事

照片记住了风景，你还记得当时的心情。

**映述把“边看边说”变成剪辑方式：**导入照片、视频和实况照片，看到想留住的画面时按 **R**。画面和配乐停下，等你说完；再按 **R**，本地 AI 将这一句转为文字，留在同一画面上，然后继续播放。

你可以把感想变成字幕、贴纸、手记，或交给一位无声的黏土旅行者，用气泡陪你讲述。整理好顺序与配乐，导出一部 MP4，或一组带字 PNG。

> 当前为持续迭代中的原生应用原型。发布包面向 Apple Silicon，使用本地 ad-hoc 签名，尚未经过 Apple 公证；独立本地 AI 需在新 Mac 上显式准备模型。

## 一次口述，留在一个画面

<p align="center">
  <img src="docs/showcase/workflow.png" alt="导入素材，观看并按 R 暂停，口述后按 R 结束，本地识别和整理，文字落到原画面并续播，最后导出" width="100%">
</p>

1. **导入与初剪。** 从系统相册选择照片、视频、Live Photo，或导入本地文件。默认按拍摄时间排列，自动安排停留时长。
2. **边看边说。** 按 **R** 冻结画面与配乐；再按 **R** 结束。本地识别与整理后，文字附到刚才的片段并续播。录制期间不逐字显示转写。
3. **改成自己的表达。** 点击画面上的文字即可纠错，也可换样式、调整显示时间、查看识别原稿；完成的编辑支持撤销。
4. **带着故事离开。** 导出带配乐的 MP4，或有序的带字 PNG，继续用于相册分享或其他编辑工具。

## 让回忆成片的细节

| 能力 | 你能做什么 |
| --- | --- |
| **画面暂停，表达不赶时间** | 口述始终绑定停住的片段；处理完成后从原位置续播，避免一句话追着多个画面跑。 |
| **本地识别与文字整理** | Qwen3-ASR 识别声音，Qwen2.5 整理文字。保留识别原稿；改写未通过保守检查时保留完整原稿。可选 DeepSeek 文字整理。 |
| **四种感想呈现** | 字幕、贴纸、手记、小人气泡。多种样式可同时出现并自动避让；小人做一次无声侧转。 |
| **顺序与停留时间可控** | 拍摄时间、智能叙事、文件名、导入顺序、手动五种顺序；本机 Vision 与音乐节拍辅助安排时长，给文字留出阅读时间。手调片段优先。 |
| **照片与动态一起讲述** | 支持常见图片与视频；完整 Live Photo 按一段动态素材导入。移除只影响项目，原文件保留；撤销同时恢复关联文字。 |
| **配乐有来源** | 场景分析生成风格关键词，搜索 CC0 / CC BY 曲目；最长 20 秒渐进试听，下载后可离线使用，导出保留署名说明。 |
| **视频与图片两种出口** | MP4 合成画面、文字与配乐；PNG 沿用文字外观并保留顺序、时间与原文索引。 |

自动编排调整的是照片停留时长和视频选段，视频保持正常播放速度；当前没有变速曲线。Vision 提供画面特征与有限重排建议，照片对你的私人意义仍由你决定。

## 你的素材，在哪里处理

默认的独立本地 AI 链路在模型准备完成后可离线运行。首次准备会下载公开依赖和模型，联网曲库与可选云端整理分别工作。

| 使用方式 | 处理内容与位置 | 启用条件 |
| --- | --- | --- |
| **独立本地 AI** | 音频由本机 Qwen3-ASR 识别，文字由本机 Qwen2.5 整理；照片、视频、音频和文字不上传。 | 一次性准备 Python / MLX 与两组模型，无需 API Key。 |
| **系统本机识别** | 使用当前 Mac 可用的 Apple 本机中文识别资源；资源不可用时明确提示。 | 选择“系统本机”，按系统要求授权或显式准备资源。 |
| **Apple 系统服务** | 音频可能经 Apple 联网处理。 | 用户明确选择此模式；不会因本机识别失败而自动切换。 |
| **DeepSeek 整理** | 仅发送本句识别文字和提示词；语音仍在本机识别。API Key 存本机钥匙串。 | 用户配置并开启，调用可能产生 API 费用。 |
| **公开配乐曲库** | 发送搜索关键词，获取公开曲目元数据与音频；画面和感想原文不上传。 | 联网检索、试听或下载时。 |

独立 AI 模式每句最长 120 秒，录音仅暂存在内存，不写入录音文件、不进入项目或成片。**当前成片使用独立配乐，不包含原视频声音或口述录音。** 识别与改写仍可能出错，应用保留原稿和手动纠错入口；尚无真人口音与噪声场景的准确率承诺。

## 开始使用

从 [v0.11.0 Release](https://github.com/bill-gx114/yingshu/releases/tag/v0.11.0) 获取 Mac 应用包。首次运行需要按系统提示允许麦克风；系统识别模式还可能需要语音识别授权。可先打开应用内置的原创示例熟悉流程。

独立本地 AI **不随应用包分发**。在另一台 Apple Silicon Mac 上，取得本仓库后运行：

```sh
bash scripts/prepare-local-ai.sh
```

脚本显式下载固定版本的公开依赖与模型，核验来源、许可及文件哈希；两组模型合计约 **1.89 GB**，另需运行环境空间。准备完成后重新打开应用，在“口述选项 → 语音与整理设置”查看状态。完整说明见 [本地 AI](docs/本地AI说明.md)。

界面的部署目标为 macOS 14+；当前独立 AI 链路只在一台 Apple Silicon Mac 上做过真实模型验收，其他机型与系统组合仍需验证。系统本机识别的可用性取决于系统版本和中文资源。未经过 Apple 公证的应用可能受到 macOS 安全检查。

**常用快捷键：** `R` 开始 / 结束口述 · `空格` 播放 / 暂停 · `⌘I` 导入 · `⌘T` 写一句 · `⌘S` 保存 · `⌘Z` 撤销。

从文件导入的素材由项目引用，请保留原文件位置；从相册选择器导入的资源会持久保存到应用自己的本机数据目录。项目目前不打包全部素材用于迁移。

## 工程一览

<p align="center">
  <img src="docs/showcase/architecture.png" alt="映述架构：原生编辑器连接本地媒体、编排和 AI 运行时；可选文字整理与授权曲库独立联网" width="100%">
</p>

应用以 **SwiftUI + AVFoundation + Vision + Speech** 构建，Swift 应用层没有第三方包依赖。独立 AI 由受控的本机 Python / MLX 进程执行，与项目文件及媒体导出分开。

```text
Sources/YingShu/       原生编辑器、项目状态、导入、编排与导出
Resources/            原创示例、界面资源、独立 AI worker
scripts/              构建、模型准备与针对性验证
Tests/                状态、媒体、AI 边界与导出检查
docs/                 使用说明、设计与项目展示
```

在安装 Swift 工具链的 Mac 上构建：

```sh
bash scripts/build-app.sh
```

产物为 `dist/映述.app`，构建脚本打包资源并进行本地 ad-hoc 签名。当前构建验证使用 Swift 6.4，以 Swift 5 语言模式和 macOS 14 为部署目标。应用运行不依赖 ffmpeg；部分媒体验证脚本需要 ffmpeg / ffprobe。

验证入口、测试依赖与覆盖范围见 [开发与验证](docs/开发与验证.md)。自动化验证使用生成或公开样本，不能替代真人麦克风、真实 iPhone / iCloud 素材与其他 Mac 的端到端验收。
